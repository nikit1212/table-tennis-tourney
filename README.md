# TableTennisTourney

Пока что заготовка приложения для создания турниров на настольному теннису.

Стек:
- node.js
- Angular v20
- ngRx
- RxJs
- Material

Цвета и шрифты:
 - Основной цвет: #009BCE
 - Шрифт: TT Norms Pro

## Development server
To start backend, run:
```bash
  cd backend
  npm run dev
```

To start a local development server, run:

```bash
  ng serve
```
